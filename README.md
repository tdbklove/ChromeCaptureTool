# ChromeCaptureTool

具有單張截圖與長條截圖功能的 Chrome 擴充功能。會自動偵測網頁中的圖片並框選，長條截圖時自動找出廣告、間隔與左右空白作為移除範圍，再輸出成乾淨的長圖。

## 功能

### 單張截圖
- 擷取目前看得到的畫面，自動去掉捲軸。
- 自動偵測畫面中的圖片、影片、畫布（canvas）、向量圖（svg）與 CSS 背景圖，並以綠框標示。偵測的最小尺寸可在設定頁調整（預設 40 像素）。
- 每個偵測框都可以拖曳邊線調整範圍，也可以在截圖上自行拖曳框選。
- 可單獨下載，或勾選後一次批次下載。

### 長條截圖
- 自動捲動整個網頁、分段截圖並拼接成長圖，等待每一段的圖片載入完成才拍攝。
- 自動隱藏固定在畫面上的頁首、浮動按鈕與 Cookie 提示，避免在每一段重複出現。
- 支援在頁面內某個區塊捲動的網站（例如 Gmail、Notion）。
- 自動偵測可移除的範圍，預設全部移除並以紅色標示（取消勾選即可保留）：
  - 圖片之間的間隔（包含偵測到的廣告）
  - 左右兩側的空白
  - 頂部、底部區域（圖片上方與下方的空間）
- 長圖的最上方與最下方一定有可拖曳的邊線（即使沒有偵測到空白或廣告），可以上下拖曳裁掉頁首、頁尾等內容，控制整張圖的高度。
- 在預覽區點擊可切換「移除／保留」，拖曳邊線可調整範圍，也可以手動新增移除區域。
- 長圖過長時會在間隔處自動分段；可以單獨下載每一段，或在段落清單（或每段卡片）勾選段落後，一次「個別下載勾選的段落」，或「合併勾選的段落」成一張長圖。
- 勾選的段落合計超過單張圖片的高度上限時（PNG／JPEG 為 30,000 像素，WebP 為 16,383 像素），勾選的項目會以紅色標示；按下合併時會先說明，確認後自動分成多張下載。
- 擷取途中可以隨時停止（例如不想截到下方的評論區）：按選單中的「停止截圖」，或再按一次 `Alt+Shift+L`。已擷取的部分會保留並開啟編輯頁。
- 頁面很長時會分批擷取，下載完一批後按「繼續截圖」擷取下一批。

### 翻頁截圖
- 適用於按鍵盤「→」鍵可以看下一張圖片的網頁（例如相簿、看圖彈窗、漫畫閱讀器），無法用捲動長截圖時使用。
- 按「翻頁截圖」：會擷取畫面中的主圖，自動按「→」鍵翻到下一張，重複直到圖片不再變化或回到看過的圖片。
- 圖片要點開彈窗才會顯示的網站，請先點開彈窗（顯示第一張圖）再開始。
- 每一頁都會等到新圖片完全顯示（淡入動畫結束、位置不再移動、高解析度圖片載入完成）才擷取；只擷取最上層的圖片，不會誤擷取彈窗後方的圖片。
- 按「→」鍵後若沒有換頁（例如看圖程式還在播放動畫而忽略按鍵），會自動再按一次。
- 每頁輸出一張圖，在編輯頁以清單列出，可單獨下載、複製或勾選後批次下載（檔名為 page01、page02……）。
- 擷取途中可以按「停止截圖」或再按一次 `Alt+Shift+K` 停止，已擷取的頁面會保留。
- 單次最多 60 頁；頁數很多時會分次擷取，下載後回到原網頁從下一頁繼續即可。
- 只支援用「→」鍵翻頁的網站；按「→」鍵沒有反應的網站無法使用。

### 預覽與編輯
- 預覽區可以縮放：「符合寬度」、「實際大小」、「－／＋」，或在預覽區按住 `Ctrl` 並滾動滑鼠滾輪（以滑鼠位置為中心縮放），方便精確調整邊線。
- 每張圖片、每段長圖與手動選取範圍都可以「複製」到剪貼簿，直接貼到聊天軟體或文件中。
- 調整偵測框、移除區域、勾選等操作都可以復原與重做。

| 按鍵 | 作用 |
| --- | --- |
| `Ctrl+Z` | 復原 |
| `Ctrl+Y` 或 `Ctrl+Shift+Z` | 重做 |
| `Esc` | 取消手動選取、新增移除框模式，以及目前點選的框 |
| `Delete` | 刪除目前點選的自訂移除框（長條截圖） |

### 下載
- 檔名格式為「網站_截圖時間_編號」，例如 `example.com_20261031-142530_img01.png`，不同次截圖不會互相覆蓋。
- 圖片格式可選 PNG（無損）、JPEG 或 WebP，JPEG／WebP 可調整品質，檔案通常能小很多。
- 在設定頁可以選擇儲存位置，設定會被記住：
  - **Chrome「下載」資料夾**：存到「下載」底下的子資料夾（預設為 `ChromeCaptureTool`），可選擇依網站分資料夾、每次詢問存檔位置。
  - **自訂資料夾**：存到電腦上任一資料夾，下載時不會跳出視窗。重新開啟瀏覽器後第一次下載，Chrome 可能會再詢問一次是否允許。

### 其他
- 關閉編輯頁時會自動清除暫存的截圖；瀏覽器重新啟動時也會清除遺留的暫存。
- 單張截圖與長條截圖各自使用獨立的編輯頁，互不影響。

## 安裝

本擴充功能尚未上架 Chrome 線上應用程式商店，請以「載入未封裝項目」的方式安裝：

1. 下載本專案：按 GitHub 頁面上的 **Code → Download ZIP** 並解壓縮，或使用 `git clone`。
2. 在 Chrome 網址列輸入 `chrome://extensions` 並開啟。
3. 開啟右上角的「**開發人員模式**」。
4. 按「**載入未封裝項目**」，選擇本專案的資料夾（含有 `manifest.json` 的那一層）。
5. 建議按工具列的拼圖圖示，將「My Screenshot Cropper」釘選到工具列。

更新時，下載新版本覆蓋原資料夾後，回到 `chrome://extensions` 按擴充功能上的「重新載入」（↻）即可。

需要 Chrome 116 以上版本。

## 使用方式

| 操作 | 方式 |
| --- | --- |
| 開啟截圖選單 | 按工具列圖示，或 `Alt+Shift+M` |
| 擷取目前畫面 | 選單中的「擷取目前畫面」，或 `Alt+Shift+S` |
| 長條截圖 | 選單中的「自動捲動並拼接」，或 `Alt+Shift+L` |
| 翻頁截圖 | 選單中的「翻頁截圖」，或 `Alt+Shift+K`（圖片在彈窗中時，請先點開彈窗） |
| 下載與快捷鍵設定 | 選單下方的「下載位置與快捷鍵設定」，或編輯頁右上角的「下載設定」 |

快捷鍵可以在 `chrome://extensions/shortcuts` 修改。用快捷鍵截圖失敗時，工具列圖示會顯示紅色的「!」，滑鼠移到圖示上可以看到原因。

**截圖進行中請勿切換分頁、捲動或操作網頁**，否則會拍到錯誤的畫面；長條截圖偵測到切換分頁時會自動停止。

### 無法截圖的頁面
Chrome 不允許擴充功能擷取以下頁面：`chrome://` 開頭的內建頁面、Chrome 線上應用程式商店，以及其他擴充功能的頁面。

## 權限說明

| 權限 | 用途 |
| --- | --- |
| `activeTab` | 只有在你按下按鈕或快捷鍵時，才能存取目前的分頁並截圖 |
| `scripting` | 在網頁中偵測圖片位置、捲動頁面、暫時隱藏固定元素 |
| `storage` | 記住下載設定與長截圖的進度 |
| `downloads` | 將圖片存到「下載」資料夾的指定子資料夾 |

截圖只會暫存在你的電腦中（瀏覽器的 IndexedDB），不會上傳到任何地方。

## 專案結構

```
manifest.json         擴充功能設定
background.js         背景程式：截圖、長截圖流程、暫存清除、快捷鍵
popup.html/js/css     工具列選單
editor.html/css       編輯頁
editor/               編輯頁的程式
  main.js             進入點：載入截圖、串接各模組
  canvas.js           預覽區（截圖層與標示層）
  interaction.js      滑鼠操作
  single-mode.js      單張截圖：偵測框與結果清單
  stitch-mode.js      長條截圖：拼接、移除區域、分段
  output.js           裁切、縮圖、下載與複製
  history.js          復原／重做
options.html/js/css   設定頁
lib/                  共用程式
  page-scripts.js     注入網頁執行的函式（偵測、捲動、隱藏固定元素）
  stitch-plan.js      拼接與分段的計算
  db.js               暫存截圖（IndexedDB）
  downloads.js        下載與檔名
  settings.js         下載設定
icons/                圖示
```

本專案不需要安裝 Node.js 或任何建置工具，修改程式後在 `chrome://extensions` 按「重新載入」即可。
